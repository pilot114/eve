# eve

Автоматизация EVE Online по экрану: захват экрана или окна, слежение за выбранными областями, OCR и
автоматические нажатия клавиш; оверлей поверх окон. Плюс краулер корпораций альянса и статус-страница.

```bash
make install          # .venv (с системными pycairo/PyGObject) и зависимости
make select-regions   # выделить мышью области слежения
make run              # запуск; make view — с записью того, что видит программа
make crawl ALLIANCE=Goonswarm_Federation
```

Нажатия идут через uinput — пользователю нужен доступ к `/dev/uinput`.
