# EVE Status — мини-дашборд EVE Online

Минималистичный сайт со статусом сервера, числом игроков, реалтайм-статистикой
и официальными новостями EVE Online.

Интерфейс разбит на вкладки (**Сводка / Опасность / Вормхолы / История / Новости**),
чтобы не скроллить — шапка со статусом сервера и полоса EVE-времени видны всегда.
Переключение вкладок — на чистом CSS (скрытые `radio` + `:checked`), без JS.

Игровые термины (PLEX, инкурсии, sov, раттинг, хайсек/лоусек/нулсек, классы
вормхолов и т.д.) снабжены поясняющими подсказками при наведении: заметные
заголовки — CSS-плашки (класс `.tip` + `data-tip`), мелкие чипы в списках —
нативные `title`.

Архитектура нарочно простая:

- **`index.html` + `style.css` + `app.js`** — статический сайт. Только HTML и CSS,
  крошечный JS читает `data.json` и подставляет значения. Никакого бэкенда.
- **`update.php`** — отдельный скрипт-сборщик. Ходит в API и складывает всё в
  `data.json`. Запускается по расписанию (cron), сайт его не вызывает.
- **`data.json`** — единственный «стейт». Сайт показывает то, что в нём лежит.

```
eve-status/
├── index.html      разметка
├── style.css       оформление (тёмная тема) + CSS-вкладки графиков
├── app.js          fetch data.json/history.json → DOM, рисует SVG-графики
├── update.php      сборщик данных (cron)
├── data.json       текущие показатели (генерируется update.php)
├── history.json    история показателей для графиков (растёт со временем)
├── systems_cache.json  кэш имён/security систем (служебный, копится)
└── README.md
```

## Что показывается

| Блок                | Источник |
|---------------------|----------|
| Статус сервера      | ESI `/status/` (online / VIP / offline) |
| Игроков онлайн      | ESI `/status/` → `players` |
| Аптайм сервера      | ESI `/status/` → `start_time` (тикает в браузере) |
| EVE-время + даунтайм | вычисляется в браузере (UTC, до 11:00) |
| Цена PLEX           | ESI `/markets/prices/` (средняя) |
| Sov-кампании        | ESI `/sovereignty/campaigns/` |
| Версия сервера      | ESI `/status/` → `server_version` |
| Новости / изменения | RSS форума «EVE Information Portal» |

### Для исследователя космоса

| Блок                | Источник |
|---------------------|----------|
| Опасность (бои)     | ESI `/universe/system_kills/` — топ систем по kills кораблей+подов за час |
| Раттинг (NPC)       | ESI `/universe/system_kills/` → `npc_kills` |
| Трафик (прыжки)     | ESI `/universe/system_jumps/` — оживлённые системы / возможные кемпы |
| Инкурсии (детали)   | ESI `/incursions/` + резолв имён `/universe/names/` (локация, статус, influence, босс) |
| Коннекшены Thera/Turnur | EVE-Scout `api.eve-scout.com/v2/public/signatures` (назначение, класс, размер, время жизни) |
| Лут сканинг-сайтов  | ESI `/markets/prices/` по курируемому списку (см. `LOOT` в `update.php`) |

Имена и security систем резолвятся через ESI и кэшируются в `systems_cache.json`
(эти данные статичны), поэтому сетевых запросов почти нет после прогрева. Имена
систем в списках — ссылки на карту [DOTLAN EveMaps](https://evemaps.dotlan.net/).

### Графики истории

Раздел «История» показывает изменение показателей во времени: **игроки**, **PLEX**,
**инкурсии**, **sov-кампании** (переключаются вкладками). Каждый запуск `update.php`
дописывает точку в `history.json`; хранятся последние `HIST_MAX` точек (по умолчанию
1440 — это ~24 ч при запуске раз в минуту).

Графики рисуются вручную как inline-SVG (без сторонних библиотек), переключение
вкладок — на чистом CSS. JS только читает JSON и строит SVG. На каждом графике
показаны пунктирная линия **среднего значения**, вертикальные засечки **по каждому
часу** (UTC, подписи прорежены, чтобы не накладывались) и **интерактивная подсказка**:
при наведении курсора появляется перекрестие и плашка со временем и значением
ближайшей точки.

> История накапливается со временем: сразу после первого запуска точек мало и
> линия почти плоская. Полноценная суточная кривая появится, когда cron поработает.

## Запуск локально

Сначала сгенерировать данные, затем поднять любой статический сервер:

```sh
php update.php          # создаст data.json
php -S localhost:8000   # открыть http://localhost:8000
```

(PHP-сервер используется только чтобы отдать статику; страница работает и под
nginx/Apache — это просто файлы.)

## Автообновление данных (cron)

Раз в минуту:

```cron
* * * * * /usr/bin/php /путь/к/eve-status/update.php >/dev/null 2>&1
```

Минута — комфортная частота: число игроков и статус меняются медленно, а ESI
просит не злоупотреблять запросами. Сайт независимо перечитывает `data.json`
тоже раз в минуту.

## Настройка

Всё вверху `update.php`:

- `USER_AGENT` — ESI просит указать контакт разработчика, поставьте свой email.
- `NEWS_LIMIT` — сколько новостей сохранять.
- `NEWS_RSS` — лента новостей (по умолчанию официальный раздел форума).
- `HIST_MAX` — сколько точек истории хранить (длина графиков).
- `TOP_N` — длина топов «опасность/трафик».
- `LOOT` — курируемый список лута (type_id → имя) для тикера цен.

## Зависимости

PHP с расширением cURL (проверка: `php -m | grep curl`). Для сайта — ничего,
обычный браузер.
